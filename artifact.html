Original and enhanced artifact

InventoryApp

An Android inventory app in Java that I built for CS 360 Mobile Architecture and Programming and then reworked for CS 499. Each user logs in to their own private inventory, browses it in a grid, searches and sorts it, and can get a text message when an item runs low.

Original, CS 360

About 1,200 lines across eight classes and four screens, with a hand written SQLite helper, single round SHA 256 passwords, and one placeholder test.

  • Browse the original code
  • Download it as a zip

Enhanced, CS 499

Repositories and ViewModels, PBKDF2 passwords with owner checks on every item, trie search and a low stock heap, and a Room database with a tested migration. 84 tests, all passing.
